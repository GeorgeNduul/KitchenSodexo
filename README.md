# KitchenSodexo

A mobile application designed for streamlined kitchen operations, including creating and editing recipes.


<img width="477" height="831" alt="image" src="https://github.com/user-attachments/assets/558f2707-3f5a-43d3-848a-d4cd00553f44" />

## Features
- **Real-Time Menu Tracking:** Browse daily and weekly meal offerings.
- **Order Management:** Place and track food orders on the go.
- **Role-Based Access:** Customized interfaces for kitchen staff and end users.
- **Push Notifications:** Instant updates on menu changes and order status.

## Tech Stack
* **Framework:** React Native (Expo) / Flutter
* **Language:** TypeScript / Dart
* **State Management:** Redux Toolkit / Riverpod
* **Backend:** Node.js / Firebase

## Prerequisites
Before starting, ensure you have installed:
* [Node.js](https://nodejs.org/) (v18+)
* [Xcode](https://developer.apple.com/xcode/) (for iOS simulator, macOS only)
* [Android Studio](https://developer.android.com/studio) (for Android emulator)
* CocoaPods (`sudo gem install cocoapods`)
